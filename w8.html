stage 0 · did the training work? · 訓練有沒有效？

Did the training help them jump higher?

訓練有沒有幫助球員跳得更高？
Summary 總結
  1. A difference after training is not an improvement. To see improvement, every player also needs a value from before training.訓練後的差距不等於進步。要看進步，每位球員也要有訓練前的數值。
  2. Change = Post − Pre for each player. The coach’s question compares the two changes: +4.00 − (+1.00) = 3.00 cm.變化量 = 每位球員的後測 − 前測。教練的問題是比較兩組的變化：+4.00 −（+1.00）= 3.00 公分。
  3. A pre-test adds a factor, Time (Pre, Post). One more training programme adds a level to Training, not a factor.加入前測 = 多一個因子「時間」（前測、後測）。多一種訓練方式 = 訓練這個因子多一個水準，不是多一個因子。
  4. Two factors with two levels each: 2 × 2 = 4 cells. 16 is the number of players; 32 is the number of measurements.兩個因子、各兩個水準：2 × 2 = 4 格。16 是球員人數；32 是測量筆數。

stage 1 · between or within? · 受試者間還是受試者內？

Follow one player, factor by factor

每個因子都追蹤同一個人
Summary 總結

For each factor, follow one person (or one unit, such as one game): does this person appear in every level of the factor? Yes → within-subjects. Only in one level → between-subjects.每個因子都追蹤同一個人（或同一個單位，例如一場比賽）：這個人有沒有出現在這個因子的每一個水準？有 → 受試者內。只在其中一個水準 → 受試者間。

  • between × between → two-way ANOVA受試者間 × 受試者間 → 二因子變異數分析
  • between × within → mixed ANOVA受試者間 × 受試者內 → 混合設計變異數分析
  • within × within → two-way repeated-measures ANOVA受試者內 × 受試者內 → 二因子重複量數變異數分析

The tool needs four things together: the DV type, the number of factors, the levels of each, and between or within for each.選工具要同時看四件事：依變項的類型、因子數、每個因子的水準數，以及每個因子是受試者間或受試者內。

Watch for 注意

  • Time (pre–post, sessions) is almost always within.時間（前後測、訓練次數）幾乎都是受試者內。
  • Matching people to make the groups comparable (配對分組) still puts each person in one group: between, unless the analysis keeps the pairs.為了讓兩組相近而配對分組，每個人仍然只在一組：受試者間；除非分析時保留配對。
  • A random order of conditions, when everyone did every condition, is within, not random groups.每個人每個條件都做、只是順序隨機：受試者內，不是隨機分組。
  • Several outcomes are several DVs, not a second factor.好幾個結果是好幾個依變項，不是第二個因子。
  • The unit is not always a person: in match analysis, follow one game.單位不一定是人：比賽分析就追蹤一場比賽。
  • Not every study has groups: two numbers measured on every person, asking whether they go up and down together, is a relationship (Pearson r, last row below).不是每篇論文都有分組：每個人都量了兩個數值，問它們是否一起高低，就是關係（皮爾森相關，下表最後一列）。

Jamovi: a within factor = several columns (one row = one person); a between factor = one column of group labels.Jamovi：受試者內因子 = 好幾欄（一列 = 一個人）；受試者間因子 = 一欄組別名稱。

stage 2 · interaction and main effects · 交互作用與主效應

One ANOVA, three questions. Which one did the coach ask?

一個變異數分析問三個問題。教練問的是哪一個？
Summary 總結
  1. Group: with Pre and Post averaged, do the two groups differ in overall level? (main effect)組別：把前後測平均後，兩組的整體水平有沒有差別？（主效應）
  2. Time: with the two groups averaged, did jump height change? (main effect)時間：把兩組平均後，前後有沒有改變？（主效應）
  3. Group × Time: did the two groups change differently? (interaction)組別 × 時間：兩組的變化是否不同？（交互作用）

Choose the row by the research question, not by the smallest p. “Did the training group improve more than control?” is the interaction.按研究問題選要讀的那一列，不是挑最小的 p。「訓練組有沒有比對照組進步更多？」就是交互作用。

How to see it 怎麼看

parallelThe same change in both groups, whether the lines rise or stay flat.兩組變化一樣，不管線有沒有上升。
not parallelThe two groups changed differently in this sample. Sample lines are almost never exactly parallel: the Group × Time test decides.這個樣本中兩組變化不同。樣本的線幾乎不會完全平行：由組別 × 時間的檢定決定。
3.00 cmDifference of differences = (42.00 − 38.00) − (39.50 − 38.50) = 4.00 − 1.00 = 3.00 cm.差異的差異 = (42.00 − 38.00) − (39.50 − 38.50) = 4.00 − 1.00 = 3.00 公分。
p and pOne group significant and the other not is not a test of “more”: test the difference in change (Group × Time).一組顯著、另一組不顯著，不是在檢定「比較多」：要直接檢定兩組變化的差（組別 × 時間）。

The dashed line and the diamonds are how this page draws the averages. First ask what was averaged: the dashed line averages the two groups at each time (Time); the diamonds average each group’s Pre and Post (Group).虛線和菱形只是這個頁面畫平均數的方式。先問平均了什麼：虛線是每個時間點把兩組平均（時間）；菱形是每組把自己的前後測平均（組別）。

A Time effect alone does not show that training worked: the control group changes too (season, practice, learning the test).只有時間效果，不代表訓練有效：對照組也會變（賽季、練習、熟悉測驗）。

stage 3 · read the result · 讀結果

F(1, 14) = 9.33, p = .009, ηp² = .40: what does it say?

F(1, 14) = 9.33、p = .009、ηp² = .40：它說了什麼？
Summary 總結
  • Read the Group × Time row first. If it is significant, describe it with simple effects: the change inside each group.先讀組別 × 時間那一列。顯著的話，用簡單效果描述它：每一組裡面的變化。
  • With a significant interaction, the main effects are only averages over a pattern that differs.交互作用顯著時，主效應只是把不同的模式平均起來。

What the result says 結果說了什麼

Group × Time F saysEvidence that the change differs between the groups: 3.00 cm more in the plyometric group, F(1, 14) = 9.33, p = .009.交互作用 F 說：有證據顯示兩組的變化不同，增強式組多 3.00 公分，F(1, 14) = 9.33，p = .009。
Simple effects sayWhere: plyometric +4.00 cm [2.51, 5.49], p < .001; control +1.00 cm [−0.49, 2.49], p = .172.簡單效果說：變化在哪裡：增強式組 +4.00 公分 [2.51, 5.49]，p < .001；對照組 +1.00 公分 [−0.49, 2.49]，p = .172。
Neither saysThat the control group did not change; that every player improved; that the training caused the gain (that depends on how players were allocated and on the design).兩者都沒說：對照組完全沒變；每位球員都進步；進步是訓練造成的（這要看球員怎麼分組，以及研究設計）。

How to read it 怎麼讀

F = 9.33F = MSGroup × Time ÷ MSerror = 18.00 ÷ 1.93 = 9.33. In a 2 × 2 it is t²: the 3.00 cm gap between the changes is 3.05 SEs from 0 (3.054² = 9.33).F = 交互作用均方 ÷ 誤差均方 = 18.00 ÷ 1.93 = 9.33。在 2 × 2 裡它等於 t²：兩組變化差 3.00 cm，離 0 有 3.05 個標準誤（3.054² = 9.33）。
(1, 14)Interaction df = (2 − 1)(2 − 1) = 1; error df = (N − groups) × (levels of Time − 1) = (16 − 2) × (2 − 1) = 14. Groups = the levels of the between factor (plyometric, control = 2).交互作用自由度 = (2 − 1)(2 − 1) = 1；誤差自由度 = (N − 組數) × (時間的水準數 − 1) = (16 − 2) × (2 − 1) = 14。組數 = 受試者間因子的水準數（增強式、對照 = 2）。
p = .009If the change were the same in both populations, a difference this large would be rare.如果兩個母體的變化一樣，這麼大的差距很少見。
ηp² = .40Partial eta squared = SSeffect ÷ (SSeffect + SSerror) = 18.00 ÷ (18.00 + 27.02) = .40. Within-subject ηp² runs high: compare it only with studies of the same design.偏 η² = 效果平方和 ÷（效果平方和 + 誤差平方和）= 18.00 ÷ (18.00 + 27.02) = .40。受試者內的 ηp² 通常偏高：只和設計相同的研究比較。

Report 報告

A 2 (Group) × 2 (Time) mixed ANOVA: Group × Time F(df₁, df₂), p, ηp²; then the change in each group: M, SD, change, 95% CI, t, p.先寫設計和交互作用的 F(df₁, df₂)、p、ηp²；再寫每一組的變化：M、SD、變化量、95% CI、t、p。

Two planned comparisons (Pre vs Post in each group), no correction. Comparing many pairs → Holm or Bonferroni, named in the Methods.事先計畫的兩個比較（每組的前測 vs 後測），不校正。要比較很多對 → 用 Holm 或 Bonferroni，並在方法寫明。

stage 3.1 · before you trust F · 相信 F 之前

Before you trust F: three checkers

相信 F 之前：三位檢查員
Summary 總結
  1. Before trusting F, three checkers each ask one question about the data. Means are about high or low; variances are about spread.相信 F 之前，三位檢查員各問一個關於資料的問題。平均數講高低，變異數講散不散。
  2. Normality looks at the shape of the residuals; Levene compares the spread within groups; sphericity compares the spread of the differences between each pair of repeated measurements.Normality 看殘差的形狀；Levene 比較組內散布；Sphericity 比較各對重複測量差值的散布。
  3. Residual = the value actually measured − the value the model predicts. Here: a player’s change − the mean change of their own group (+5.1 − 4.0 = +1.1 cm).殘差 = 實際量到的數值 − 模型預測的數值。這裡是：一位球員的變化量 − 自己組的平均變化量（+5.1 − 4.0 = +1.1 公分）。
  4. p < .05 is usually a warning; p ≥ .05 only means that enough evidence against has not been found, not proof that there is no problem.p < .05 通常是警號；p ≥ .05 只是還沒找到足夠的反對證據，不等於證明完全沒有問題。

library(afex)      # aov_ez(): ANOVA with between and within factors
library(emmeans)   # simple effects
library(ggplot2)   # interaction plot

# #2 Prepare factors
df$Group <- factor(df$Group, levels = c("Control", "Plyometric"))
df$Time  <- factor(df$Time,  levels = c("Pre", "Post"))

# #3 Two-way mixed ANOVA (2 × 2): Group between, Time within
aov_res <- aov_ez(id = "ID", dv = "CMJ", data = df,
                  between = "Group",   # different players 受試者間
                  within  = "Time",    # the same players 受試者內
                  type = 3)
summary(aov_res)
library(effectsize)
eta_squared(aov_res, partial = TRUE, ci = 0.95)

# #4 Simple effects: the change inside each group
emmeans(aov_res, pairwise ~ Time | Group)
emmeans(aov_res, pairwise ~ Group | Time)
emm_time_by_group <- emmeans(aov_res, ~ Time | Group)
confint(pairs(emm_time_by_group))   # 95% CIs of the change
contrast(emm_time_by_group, interaction = "pairwise", by = NULL)

# #5 Interaction plot: mean ± SE
ggplot(df, aes(x = Time, y = CMJ, color = Group, group = Group)) +
  stat_summary(fun = mean, geom = "line", linewidth = 1) +
  stat_summary(fun = mean, geom = "point", size = 2) +
  stat_summary(fun.data = mean_se, geom = "errorbar", width = 0.15) +
  labs(x = "Time", y = "CMJ (cm)", color = "Group") +
  theme_classic(base_size = 12)

Audit a sentence, then two new studies

Summary 總結

Audit a sentence 審核一句話

  1. Find the claim.找出句子的主張。
  2. Find the number behind it.找出它依據的數字。
  3. Ask what that number can say, and what it cannot.問：這個數字能說什麼、不能說什麼。
  4. Accept, modify or reject, and say why.接受、修改或拒絕，並說出理由。

Every new study 每個新研究

DV → factors and levels → between or within for each → tool → which effect answers the question.依變項 → 因子和水準 → 每個因子是受試者間或受試者內 → 工具 → 哪一個效果回答研究問題。
