Research question 研究問題Does where an elite blocker looks (the ball, the setter’s hands or the setter’s upper body) change block initiation time?菁英攔網者看哪裡（球、舉球員的手或舉球員的上半身），會不會改變攔網啟動時間？

Design 設計8 blockers · 3 focus × 4 tactics, both within · 192 trials8 位攔網者・3 焦點 × 4 戰術，都是受試者內・共 192 次試作
Tactic 戰術Four set types with different ball speed and flight time四種舉球戰術，球速和飛行時間都不同

Model A and Model B模型 A 與模型 B

One line = one blocker. What a model fixes is the same for every line; what it does not fix can differ.
Model A: the focus effect is fixed, the starting level is not. Model B: neither is fixed.一條線 = 一位攔網者。模型固定的，每條線都一樣；模型不固定的，可以不同。
模型 A：焦點效果固定，起點不固定。模型 B：兩者都不固定。

Q0.1Linear mixed model (LMM): Model B added Intercept | ID_Focus. What may now differ between blockers?線性混合模型（LMM）：模型 B 加了 Intercept | ID_Focus。現在攔網者之間哪一樣可以不同？
The starting level (Intercept | ID), and how much focus affects her (Intercept | ID_Focus). So the Focus test counts the blockers: Den df 14 = (8 − 1) × (3 − 1).起點（Intercept | ID），和焦點對她的影響（Intercept | ID_Focus）。所以焦點的檢定數的是攔網者：分母自由度 14 = (8 − 1) × (3 − 1)。

Before writing the result寫結果之前

Q0.2Tactic has the largest F. Which effect is reported first?戰術的 F 最大。先報告哪一個效果？
Focus. The research question asks where the blocker looks. Tactic is a condition built into the design: the four sets differ in ball speed, so a large difference is expected.焦點。研究問題問的是攔網者看哪裡。戰術是設計裡的情境因子：四種戰術的球速本來就不同，差異大是預期之內。
Q0.3Tactic p < .001, Focus p = .024. Can the two p values be compared?戰術 p < .001，焦點 p = .024。兩個 p 可以比較嗎？
No. Focus is tested against 8 blockers (Den df 14). Tactic is tested against trials (Den df 159). A p value is also not an effect size.不可以。焦點用 8 位攔網者來檢定（分母自由度 14），戰術用試作來檢定（分母自由度 159）。而且 p 值不是效果量。
Q0.4Focus × Tactic: p = .820. What is written?焦點 × 戰術：p = .820。怎麼寫？
“No evidence that the focus effect depended on tactic.” Not “no interaction”: with 8 blockers, not significant is not the same as zero. The focus effect is then reported averaged over the four tactics.「沒有證據顯示焦點效果隨戰術改變。」不寫「沒有交互作用」：只有 8 位攔網者，不顯著不等於零。之後報告對四種戰術取平均的焦點效果。
The result, written for a thesis寫成論文的結果
A linear mixed model showed an effect of focus on initiation time, F(2, 14) = 4.90statistic · df, p = .024exact p, marginal R² = .53, conditional R² = .60effect size. Initiation time also differed by tactic, F(3, 159) = 76.91, p < .001, as expected from the different set trajectories. There was no evidence that the focus effect depended on tactic, F(6, 159) = 0.48, p = .820. Bonferronipost hoc comparisons showed shorter times with upper-body than hand focus (0.145 vs 0.220 s, 95% CI [0.01, 0.14]CI, p = .032); the difference from ball focus was not significant (p = .093).
